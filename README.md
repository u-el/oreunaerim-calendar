# 오르내림 캘린더

산행, 백패킹, 먹벙, 놀이벙 일정을 관리하는 웹 캘린더입니다. 일정과 인증 기록은 사용하는 브라우저에 저장됩니다.

## 화면 점검

수정한 뒤 주요 화면이 오류 없이 열리는지 한 번에 확인할 수 있어요.

```
node tests/smoke.js
```

Playwright와 Chromium이 필요해요 (`npm i -g playwright && npx playwright install chromium`).
외부 연결(Firebase, 글꼴, 날씨)은 막고 테스트용 일정을 넣어서, 휴대폰 폭(390px)과 PC 폭(1280px)에서
탭 전환, 일정 목록, 새 일정 창, 일정 상세, 피드, 닉네임, 어두운 화면을 점검해요.
가로 넘침과 드롭다운 글자 잘림도 함께 확인해요. 실패하면 ✗ 줄에 원인이 나와요.
